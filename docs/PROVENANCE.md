# Source and result notes

This repository contains cleaned implementations and selected results from a team mathematical modeling project.

Historical drafts, duplicate code versions, temporary files, prompts, and incomplete report files were excluded. The retained source code preserves the core numerical models, simulation logic, and optimization routines. Team members jointly participated in modeling, algorithm development, programming, debugging, experiments and analysis, without exclusive ownership of individual Q1–Q4 modules.

## Numerical results

- `data/q1/` contains archived validation inputs.
- `results/reference/q1/` and `results/reference/q2/` contain selected archived numerical outputs, retained without numerical edits. Q2 values describe posterior-region diameter, not measured position error.
- `results/reproduced/q1/` and `results/reproduced/q2/` contain later independent verification and selected objective re-evaluations.
- `results/reproduced/q3/` and `results/reproduced/q4/` contain later offline synthetic validation: 30 runs per retained setting, seeds 1000–1029. They are not recovered competition scores or physical robot measurements.

`src/run_simulation_experiments.py` exports results from the retained planners; it adds no search or localization algorithm. New runs write to `results/generated/`.
